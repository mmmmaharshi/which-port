# Zig as the implementation language

`which-port` is written in Zig rather than Go, Rust, or C. Measured stripped
binary size for an equivalent program: C 13 KB, Zig 490 KB, Rust 834 KB, Go
1.5 MB. Zig also cross-compiles Windows, Linux (musl and glibc), and macOS (both
architectures) from a single Windows host with one command and no extra
toolchain setup, which is why this project ships prebuilt binaries without a CI
matrix. C would have been smaller still, but it buys that 480 KB with manual
buffer management in exactly the text parsers where buffer overflows live, and it
cannot cross-compile to macOS at all. The cost accepted here is an unfamiliar,
actively-churning standard library (`std.fs.File` and
`GeneralPurposeAllocator` were both removed in 0.17) and a thinner talent pool.
